# Google Indexing Checklist

## Before launch

- [ ] Set production `APP_URL` to `https://harianmerahputih.co.id`.
- [ ] Set `APP_ENV=production` and `APP_DEBUG=false`.
- [ ] Confirm HTTPS and HTTP-to-HTTPS redirect.
- [ ] Confirm non-www canonical host policy at Hostinger.
- [ ] Verify `/robots.txt`, `/sitemap.xml`, `/news-sitemap.xml`, and `/feed.xml`.
- [ ] Verify no admin/login/preview URL appears in public navigation or sitemaps.

## After launch

1. Verify domain/property ownership in Google Search Console.
2. Inspect the homepage and one representative published article.
3. Submit `https://harianmerahputih.co.id/sitemap.xml`.
4. Verify discovery of `news-sitemap.xml`.
5. Request indexing for a small representative sample.
6. Monitor Page Indexing and Core Web Vitals.
7. Monitor News sitemap freshness and structured-data enhancements/errors.
8. Test representative article URLs with URL Inspection and Rich Results Test.

No Search Console submission or Google validation was performed during this local phase.
